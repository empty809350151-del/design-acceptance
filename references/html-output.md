# 固定 HTML 输出规范

本 Skill 的默认报告采用用户已确认的 `assets/preview.html` 样式与动效。`scripts/build_report.py` 是唯一生成入口，预览是 `assets/example-manifest.json` 的生成产物。Figma `heWxFEtEUDsUYJjFqJ7zbS` 的 `9:743` / `9:862` 是初始布局参考；后续已确认的调整以本文件和生成器为准，不要重新从原稿覆盖。

## 生成与交付

- 从清单生成报告：`python3 <skill-dir>/scripts/build_report.py <manifest.json> --output <output-dir>/design-acceptance.html`。脚本路径相对 Skill 安装目录解析，输入和输出使用任务自己的路径。
- 每次验收只修改清单内容与实际截图资源，不另写 HTML、不复制后手改预览、不注入替代 CSS/JS。用户明确要求调整模板时，修改生成器并同步生成预览。
- 页面数据、负责人、问题数量、指标和设计稿 URL 来自清单。不得将示例占位图或示例分数当作真实验收结果。
- 默认交付可发送的单文件 HTML。CSS、JavaScript、图标、实际截图、设计图、热区与遮罩全部内嵌，不依赖本机路径、临时图片链接或联网资源。原图留作工作证据，收件人只需收到 HTML 文件。
- 图片输入路径默认相对输出 HTML 所在目录解析；也可用 `--asset-dir <图片根目录>` 明确指定。支持 PNG、JPEG、WebP、GIF、BMP、本机 file URL 和 base64 raster data URI。图片缺失或空文件会阻止生成；远程截图先下载为本地文件再生成，不保留临时地址。
- 可以通过聊天工具、邮件附件或共享盘发送 HTML，接收人下载后在浏览器打开；部分工具的附件预览不执行脚本，需要下载查看。设计稿和用例链接是可选溯源入口，访问仍受原平台权限控制，不影响内嵌证据的查看。
- 本机绝对路径不是别人能打开的在线链接。如果要求点击链接直接看，需发布到用户指定或授权的静态托管空间，验证部署地址后再交付；不要把本机路径当作已发布地址。

## 当前视觉基准

- 苹方系统字体栈，白底、浅灰对比面板和卡片、蓝色控件选中态、红色问题标记。
- 大屏左栏 320px，中间对比区，右侧独立滚动问题栏 572px。≤1700px 使用 240px / 400px 两侧栏；≤1200px 问题栏进入文档流；≤720px 导航移至顶部。保留侧栏折叠能力。
- 字体已按原 Figma 基准减小 4px，配套缩紧间距；不要再次执行减字号或全局缩放。正文基准 12px；问题卡片测量说明 12px；指标描述大屏 12px、≤1700px 为 10px；问题总数字重 600。其余精确字号和断点以生成器为准。
- 大屏主要区域上内边距 36px、侧内边距 24px，中间横向留白 48px；问题类别间距 28px、卡片间距 12px；Tab 栏高 44px，工具按钮最小高度 40px。
- 标题下始终展示 24×24px Figma 原图标与蓝色“设计稿地址 >”，间隔 4px、垂直居中。有 `figma_url` 时打开真实地址；缺少 URL 时保留外观但标记禁用，不伪造链接。验收说明与用例身份信息收在页尾。
- 默认分屏：实际截图在左、设计稿在右，图注位于各自图片下方。图片保留原始长宽比，最大显示高度约 70vh。
- 固定展示字号、颜色、间距、元素尺寸四个分类；0 个问题也显示“0项”，颜色 `#13B36B`。零问题仅代表当前问题数，不等同于该类别已完成验收。问题分类可折叠；有额外问题时保留其他分类。字号问题与关联问题去重，总数来自真实问题列表。显示失败字段卡片，完整字段表折叠展示。
- 叠图工具横向排列，激活时蓝色边框；透明度滑杆保持无填充外框。滑杆轨道和滑块均不描边，保留键盘焦点提示。所有问题框初始隐藏，只展示当前选中问题；红蓝框线均为 2px，选中和脉冲动画不加粗。
- 每个问题卡片都附图片示意：字号使用锚点叠图，其余问题使用实际截图／设计稿局部对照，依据问题矩形自动裁取周边上下文。缺少矩形时展示完整源图；缺少源图时明确标注缺图，不生成虚构证据。

## 当前动效与交互

| 交互 | 固定行为 |
| --- | --- |
| 对比 Tab | 同一个白色选中底板横向平移到选中项，240ms；不能用两个按钮背景淡变代替 |
| 对比内容／页面切换 | 淡入并轻微上移，220ms；页面切换重置叠图状态与选中问题 |
| 指标数字 | 首次进入和切换验收页时，从 0 递增到目标值，1000ms ease-out；百分比保留两位小数，问题数量为整数。原生 requestAnimationFrame，无联网依赖；快速切页取消旧计数，以原始目标值重新开始；减少动态效果时直接显示最终值 |
| 展开／收起 | 按真实内容高度平滑展开或收拢，220ms；快速连续操作以最后一次意图为准，完成后恢复自适应高度 |
| 侧栏折叠 | 宽度与正文偏移同步过渡，240ms；更新按钮名称与 `aria-expanded` |
| 按钮／卡片状态 | 颜色、边框与背景过渡 160ms；问题标记淡入 180ms |
| 键盘 | 原生按钮与折叠标题支持键盘；问题卡片 Enter/Space 选中，Escape 清除 |
| 减少动态效果 | 遵循 `prefers-reduced-motion`，立即完成状态切换，无位移动画 |

使用原生 Web Animations API 与 CSS transitions，不依赖 GSAP CDN。禁止在包含固定问题栏的祖先上添加 transform 动画；这会改变固定栏定位基准并遮挡对比区。动画取消、快速切页和反向折叠不能留下固定高度、裁切或透明状态。

## 维护验证

修改生成器后重新生成示例预览，并运行：

```bash
python3 scripts/build_report.py assets/example-manifest.json --output assets/preview.html
python3 scripts/test_build_report.py
python3 scripts/test_metric_animation.py
python3 scripts/test_report_browser.py
python3 scripts/test_report_motion.py
python3 scripts/test_issue_presentation.py
python3 scripts/test_analyze_overlay.py
```

浏览器测试需要 Playwright 和 Chromium，覆盖正常／减少动画、多种屏宽、快速反向折叠、切页、键盘与固定栏定位。交付具体报告还需核对清单、截图资源与内容，示例通过不代表真实页面通过验收。

元素尺寸问题的左右图片使用相同 viewBox 宽高与显示尺寸，保持同倍率；在图上以红／蓝尺寸线标出宽、高（px），实际截图标注近似符号，并在图下显示宽高差值。数值来自清单框选坐标，不从预览显示尺寸反推；原始误差与估算说明保留。

四类问题均需图上标注：字号叠图显示截图估算／设计字号；颜色显示实际采样／设计色值及色块；间距显示已测量方向、标线和实际／设计数值；尺寸显示宽高。颜色与间距读取 `annotation` 测量数据，缺失则显示待测，不将元素外框尺寸误作间距。

标题文案固定规则：左栏品牌标题始终为 `Design Acceptance`，副标题保留 `Figma Design Review`；左栏需求标题与页面顶部眉题统一读取 `meta.project`（本次需求名称），不能使用通过／未通过状态替代；右侧验收问题英文副标题固定为 `Acceptance Issue`。

所有 details 展开／收起箭头使用用户提供的 `assets/disclosure-arrow.svg`（原始 viewBox 24×24，显示尺寸 16×16px，填充 `#0F131A`），生成时以内嵌 data URI 输出，保留 220ms 旋转过渡及减少动态效果支持；不得用文本字符或浏览器原生三角替代。

对比 Tab 在文字前使用用户提供的 `assets/compare-overlay.svg` 与 `assets/compare-split.svg`，显示尺寸 16×16px，图文间隔 6px，整体水平居中。图标内嵌到 HTML，保留单个白色底板平移动效。

点击或键盘选中右侧问题时，只更新卡片与图上框选状态，不调用自动滚动，不改变页面滚动位置和中间对比区位置。

标题下设计稿地址右侧展示“测试用例地址 >”，使用 Figma 12:1124 导出的 `assets/test-case-logo.png`（内嵌 HTML）。与设计稿链接共用字号、蓝色、24px 图标和 4px 图文间距，两入口间隔 24px，窄屏自动换行。链接读取页面或全局 `test_case_url`，缺失时保留禁用外观。

左右侧栏内容超过视口时仍可滚动，但隐藏滚动条（scrollbar-width:none 与 WebKit 滚动条隐藏）；不使用 overflow:hidden 截断内容。
